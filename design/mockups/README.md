# Mockups

Each `.dc.html` file is one screen from the design canvas (or, for `Anatomy.dc.html`, the shared anatomy figure component). They use a design-tool format: markup inside `<x-dc>`, with state and text in the `<script type="text/x-dc">` block. They are a reference for layout, spacing and copy, not production code, and they won't run on their own (`support.js` is provided by the design tool). See `docs/COPY.md` for the approved text and `docs/DESIGN.md` for tokens.
